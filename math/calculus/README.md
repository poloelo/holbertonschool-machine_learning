# Calculus

## Description

This project covers the calculus needed for machine learning: summation and
product notation, series, derivatives (power, product and chain rules),
partial derivatives, and indefinite, definite and double integrals. It mixes
multiple choice questions with Python functions that compute a series sum,
the derivative of a polynomial and the integral of a polynomial.

## Requirements

### Multiple choice questions

- The answer file contains the number of the correct answer
- All files must end with a new line

### Python scripts

- Ubuntu 20.04 LTS
- Python 3.9
- pycodestyle 2.11.1
- The first line of all files must be exactly `#!/usr/bin/env python3`
- All files must be executable and end with a new line
- All modules, classes and functions must have a documentation string
- No module may be imported

## Files

| File | Description |
| --- | --- |
| `0-sigma_is_for_sum` | Expanding a sigma notation |
| `1-seegma` | Evaluating a sum over an index |
| `2-pi_is_for_product` | Expanding a product notation |
| `3-pee` | Evaluating a product containing a zero factor |

| `6-voltaire` | Derivative of a logarithm with the chain rule |

| `9-sum_total.py` | `summation_i_squared(n)`: sum of the first n squares |
| `10-matisse.py` | `poly_derivative(poly)`: derivative of a polynomial |
| `11-integral` | Indefinite integral of a power of x |
| `12-integral` | Indefinite integral of an exponential |
| `13-definite` | Definite integral of a constant |
| `14-definite` | Definite integral over a discontinuity |
| `15-definite` | Definite integral with respect to another variable |
| `16-double` | Double integral |
| `17-integrate.py` | `poly_integral(poly, C=0)`: integral of a polynomial |
